# Bourgeon

Carnet de bord personnel tout-en-un : journal, habitudes, focus, objectifs,
matrice d'Eisenhower, révisions par répétition espacée et sport.

Application web en HTML / CSS / JavaScript, sans étape de construction.
Les données restent dans le navigateur ; elles peuvent être synchronisées
entre appareils avec Supabase (voir `js/config.js` et `outils/supabase.sql`).

- Lancer en local : ouvrir `index.html`.
- Tests : ouvrir `tests/tests.html`.
- Suivi du projet : `PLAN_Bourgeon_web.txt`.
